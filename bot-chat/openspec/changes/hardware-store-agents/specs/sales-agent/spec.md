## Purpose
Agente especializado en atención y ventas para la ferretería, brindando recomendaciones e información comercial.

## ADDED Requirements

### Requirement: Ventas y Atención al Cliente
El agente MUST atender consultas de los usuarios sobre productos, precios y recomendaciones de compra para la ferretería.

#### Scenario: Consulta de precio de producto
- **WHEN** un usuario pregunta por el precio de un producto
- **THEN** el agente devuelve la información del producto utilizando sus herramientas de búsqueda

#### Scenario: Recomendación de producto
- **WHEN** un usuario pide una recomendación sobre qué herramienta usar para una tarea
- **THEN** el agente recomienda el producto adecuado disponible en la ferretería
